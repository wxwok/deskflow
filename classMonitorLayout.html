Detailed Description

Places each computer's monitors on one shared virtual desktop.

A computer's monitors stay in the arrangement the operating system reports (local coordinates). originX/Y is added to those coordinates to place the whole group. z is the stack order: a higher value is in front. Missing or equal values keep file order, with a later computer in front. Where monitors overlap, the highest computer that is connected and available receives the pointer. A computer underneath is used only when every computer above it is missing, disconnected, or unreachable, and a higher computer takes the pointer back when it becomes available again. Leaving across a shared edge prefers that edge over a stack peek, so the crossing stays directional and the primary ReleaseAt inset still runs. Switching also happens where a monitor edge is not continued by another monitor of the same computer and does overlap a monitor of a different computer.

An empty layout leaves the legacy neighbour links in charge.
