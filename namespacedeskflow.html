◆ EiBackendReconnect

enum class deskflow::EiBackendReconnect
strong

What to do with an EIS fd from a new portal session.

libei installs exactly one backend per context. ei_setup_backend_fd() asserts !ei->backend and abort()s (SIGABRT, process status 6) when a second fd is attached to the context that already serves the previous InputCapture session. The recovery path has to destroy that context first.

Enumerator
Attach 

No backend yet. ei_setup_backend_fd() is safe.

ReplaceThenAttach 

A backend is already installed. Replace the ei context, then attach.

void deskflow::nudgeReleaseAwayFromSwitchEdges ( double & x,

const ReleaseSwitchEdge * edges,
std::size_t count,
int margin )
inline

Push a ReleaseAt point away from switch barriers inside its zone.

Mutter can re-activate InputCapture when the warp lands only a few pixels inside a barrier — observed on concave bottom edges (portrait monitor above a stacked neighbour) even ~60px in, while a ~4px left-edge return held. Clamp each matching edge by up to margin (or half the zone, whichever is smaller).
